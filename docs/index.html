Client-side demo

CAPRA AI Privacy Risk Assessor

This static demo runs the CAPRA privacy-risk scoring workflow entirely in your browser using the same taxonomy and assessment logic as the Python CLI/API/MCP tool. It is grounded in the published taxonomies Privacy in the Age of AI: A Taxonomy of Data Risks and A Taxonomy of Data Risks in AI and Quantum Computing (QAI) — A Systematic Review.

Start assessment View repository

How it works

Static taxonomy, local scoring, no backend

The page loads versioned JSON copies of the repository taxonomy from docs/data/ and performs the assessment locally in JavaScript. No server-side scoring or external runtime service is used.

Leave a risk unrated to preserve the Python tool's unrated_risks behaviour, or explicitly choose Unknown or Not applicable when that distinction matters to your review.

Assessment output

Report structure

  • Overall score and per-category scores
  • Flagged high-risk items and related cross references
  • Recommendation strings generated from the source definitions
  • Count and list of unrated risks
